# 생각과 글

LEET(언어이해·추리논증·논술), 논리학 10단원, 융 중심 심리학 10단원, 개념어·논리 어휘 66개(간격 반복), 논리적·문학적 글쓰기와 AI 첨삭을 하나로 묶은 claude.ai 아티팩트 앱.

- 앱: https://claude.ai/artifact/XTpULw72MBJiM2bwRK2n5T
- 빌드: `python3 src/build.py` (토익 앱의 CSS·PDF 코드를 가져와 index.html을 만든다)
- LEET 지문·문제는 기출 형식을 본뜬 새 연습용이다. 실제 기출은 leet.or.kr 공개 문제와 공식 해설서로.
