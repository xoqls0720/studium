# 태빈 토익 독학 · 목표 990

토익을 처음부터 만점까지 한 앱으로 공부하기 위한 한 페이지 웹앱입니다. 아이패드에서 쓰도록 만들었습니다.

- 앱 주소(claude.ai 아티팩트): https://claude.ai/artifact/QWXsekxmPFTLNtLVPGQGbM

## 기능

| 화면 | 하는 일 |
|---|---|
| 오늘 | 원서 접수까지 남은 날, 오늘 할 일, 공부 시간 |
| 로드맵 | 4단계(~450 → 700 → 900 → 990) 할 일과 현재 단계 |
| 단어 | 기본 158개 + 수준별로 Claude가 30개씩 추가. 간격 반복(1·2·4·8·16·30일) |
| 문법 | 기초 10단원 설명·퀴즈, 단원별 문제 추가 생성 |
| 파트별 | 파트1~7 새 문제 생성(난이도 4단계, 약점 유형 집중) |
| 모의고사 | LC 하프(23분)·RC 하프(37분), 시간 제한, 끝난 뒤 파트별 결과 |
| 오답노트 | 틀린 문제 자동 저장, 다시 맞히면 삭제, 이상한 문제 버리기 |
| 진단 | 20문제로 현재 수준 추정, 난이도 자동 설정 |
| 기록 | 14일 학습량, 파트별·유형별 정답률, 토익 점수 그래프 |

## 구조

```
index.html      합쳐진 최종 파일 (아티팩트에 올리는 파일)
src/app.html    화면과 동작
src/data.js     기본 단어·문법 단원·파트5·파트2 문제
build.py        src → index.html 합치기
```

## 동작 원리

- **문제 생성**: claude.ai 아티팩트의 `sample` 기능으로 Claude가 문제를 만듭니다. API 키는 쓰지 않습니다.
- **저장**: 아티팩트의 `db` 기능(본인만 읽을 수 있는 `data/users/<id>/toeic` 문서). 쓸 수 없을 때는 브라우저 저장소에만 남깁니다.
- **소리**: Claude 음성(`tts`)이 없으면 기기 내장 영어 음성으로 읽습니다.
- `sample`·`db`·`tts`는 claude.ai 안에서만 동작합니다. 다른 곳에 올리면 기본 문제와 기기 저장만 작동합니다.

## v3에서 더해진 것

- **전략 탭** — 토익 990 만점자 후기·수기에서 겹치는 방법을 정리: 900 이후는 실수 줄이기, 오답은 '묻는 것·틀린 이유' 기록, RC 시간 배분(파트5 8~10분 / 파트6 7~8분 / 파트7 57~60분, 즉시 마킹), 쉐도잉·받아쓰기, 디렉션 시간에 파트3·4 미리 읽기, 2시간 실전 체력, 단계 목표 900→950→970→990.
- **파트1 일러스트** — 문제 생성 시 장면을 그린 SVG 그림을 함께 받아 사진 문제처럼 표시. 받은 SVG는 script·이벤트 속성·외부 참조를 지우는 새니타이저(svgSan)를 거친 뒤에만 그림. 그림이 없으면 장면 설명 텍스트로 대체.
- **아이패드 홈 화면 앱** — apple-touch-icon(icon.png)과 메타 태그 추가. Safari 공유 → '홈 화면에 추가'로 전체 화면 앱처럼 열림(서비스 워커는 플랫폼상 불가라 오프라인은 안 됨).
- **기출 안내** — 실제 ETS 기출은 저작권상 포함 불가. 전략 탭에 ETS 공식 기출문제집(YBM) 병행 시기를 명시.
- 모의고사 타이머가 화면 전환 시 정리되도록 하는 수정이 소스(app.html)에 직접 반영됨.

## v4에서 더해진 것

- **굿노트 탭** — 앱이 그 자리에서 인쇄용 문서를 생성: 문장 뼈대 노트, 문법 10단원 핵심 노트, 단어 체크표(현재 단어장 전체), 오답노트 정리(묻는 것·틀린 이유 필기 칸 포함), 만점 전략 요약. '굿노트로 보내기'는 window.print()로 인쇄 화면을 열고, iPad 공유 시트에서 GoodNotes를 고르면 PDF로 들어간다. GoodNotes는 외부 쓰기 API가 없어 이 방식이 유일한 연동 경로.

## v5에서 바뀐 것

- **굿노트 보내기를 PDF로** — 아티팩트 틀 안에서는 window.print()가 막혀 있어서, 문서를 캔버스에 A4로 그려 JPEG 페이지로 만든 뒤 직접 PDF를 조립(makePdf)하고 `downloads` 기능으로 저장·공유한다. Claude iOS 앱에서는 공유 시트가 바로 떠서 GoodNotes를 고르면 된다.
- **한글 발음** — 기본 단어 158개는 data.js의 PRON 표(손으로 쓴 미국식 한글 발음, '-'는 긴 소리). 새로 받는 단어는 6번째 칸에 발음을 함께 받음. 예문·문법 예문·문제 문장은 '한글 발음 보기'를 누르면 Claude가 만들고 계정에 캐시(S.pr, 최대 3,000개). PDF의 단어 체크표에 발음 칸, 문장 뼈대 노트 예문에 발음 표기.

## 한계

- 문제는 실제 토익 형식과 난이도를 본떠 새로 만든 것이며 ETS 기출이 아닙니다. 가끔 틀린 문제가 섞일 수 있어 '이상한 문제예요' 버튼을 두었습니다.
- 파트1은 사진 대신 장면 설명으로 대신합니다.
- 서체는 마루 부리 대신 가장 가까운 부리 서체(고운바탕)를 씁니다.
